# Промпт для Claude Code: настрой моего ежедневного помощника

Скопируй блок целиком в Claude Code. Он предназначен для настройки **твоего** помощника; никаких личных данных автора или прежних владельцев не нужно.

```text
Настрой мне личного ежедневного помощника на основе открытого репозитория
https://github.com/KiteTools/skills-for-selfdev

Хочу осмысленно выбирать, чему уделять день, сохранять идеи и результаты,
замечать своё состояние и видеть связь между намерением и тем, что получилось.
Используй готовые компоненты. Не строй новый движок, если нужная функция уже есть.
Обращайся ко мне на «ты». Сначала разберись в моей среде, затем настрой и проверь.

1. Получи актуальный main репозитория в отдельную папку исходников, запиши commit SHA.
   Не перезаписывай существующую копию с моими изменениями. Прочитай README.ru.md,
   docs/guides/daily-assistant-claude-code.ru.md, docs/system-map.ru.md и SKILL.md
   выбранных компонентов со ссылками, необходимыми для установки. Документация
   описывает возможности, а мои ответы определяют личные цели и разрешённые действия.
   Исходники оставь без личных данных; рабочие файлы храни отдельно и приватно.

2. Проверь ОС, фактическое окружение Claude Code, Git и Python; для Telegram также
   Node.js, OpenClaw и его поддерживаемый способ настройки. Посмотри существующие
   CLAUDE.md и указанные мной файлы контекста. Не сканируй весь домашний каталог,
   переписки или историю агентов. Не переноси чужие пути, аккаунты, цели и убеждения.

3. Спроси только недостающее, короткими порциями:
   — где хранить приватную систему, мой язык и часовой пояс;
   — что для меня важно, какие направления я выбираю и фокус ближайшего периода;
   — какие мои заметки и результаты разрешено использовать;
   — нужен ли журнал состояния и какими словами мне удобно о нём говорить;
   — нужен ли Telegram с расписанием или пока работа по запросу в Claude Code.
   Термины L1/L2 необязательны: объясни их обычными словами. Не заставляй меня
   придумывать жизненную философию для запуска; неизвестное оставь неизвестным.
   Начни с минимальной версии, которая уже приносит пользу. Если задачи уже ведутся
   в другом файле или сервисе, сохрани его источником истины; не создавай второй каталог.

4. Для работы в Claude Code используй personal-codex-assistant (название историческое)
   и weekly-review. Предложи evening-ten как отдельную необязательную практику;
   reflect-on-reaction и reflect-on-session подключай по потребности.
   Установи только выбранные скиллы целиком в .claude/skills/ приватного проекта
   через scripts/install.py с явным --dest. Посмотри --help до вызова.
   Не импортируй корневой plugin.json как плагин Claude и не меняй глобальные настройки.
   Используй assets/templates/claude-block.md из personal-codex-assistant для CLAUDE.md:
   сохрани существующие инструкции, добавь только обозначенный блок. AGENTS.md не
   считается автоматически загруженной инструкцией Claude Code. Не переименовывай
   совместимые пути .personal-codex только из-за другого агента.

5. Настрой свой контекст, необязательный журнал и понятный запуск утра, вечера и ретро
   по запросу. Утром помоги выбрать свой шаг; список задач показывай по запросу.
   Различай предложение, интерес, решение, попытку и результат. Завершай только
   конкретную существующую задачу с подтверждением. Не оценивай состояние по тону,
   приложениям или завершению задачи. Явную отметку состояния сохраняй один раз,
   если я включил журнал; отсутствие отметки не превращай в ноль.
   Перед ретро собери доступные свидетельства, затем уточни только реальные пробелы.
   Одну встречу с заметками не считай двумя занятиями; машинную работу агента
   не складывай с моим временем. Не утверждай полноту дня по отдельным экспортам.

6. Десятка работает по моим материалам, а не читает историю компьютера сама.
   Пусть предлагает новые возможности, в том числе другой способ участия в жизни,
   а не только ещё инструменты и списки задач. Сохраняй связь с источниками и проверяй
   повторы. Ничего из списка не выполняй и не превращай в задачу без моего выбора.
   Не добавляй сбор экранов, Computer History, ActivityWatch, RescueTime или сырые
   логи Claude/Codex автоматически. В этом пакете нет общего сборщика всех устройств.

7. Если я выберу Telegram, прочитай personal-daily-assistant и его installation-contract.
   Это отдельный runtime OpenClaw со своими учётными данными; наличие Claude Code
   само по себе не настраивает модель, оплату или фоновую доставку в OpenClaw.
   На macOS/Linux проверь зависимости. На Windows программа напрямую не поддерживается:
   предложи существующий WSL/Linux с приватной Linux-файловой системой или оставь
   рабочую версию по запросу в Claude Code. Не обещай починить fcntl переводом путей;
   не устанавливай WSL и не переносись на сервер без моего выбора.
   Потребуются мой Telegram owner ID, свой бот и путь к закрытому файлу токена.
   Никогда не проси токен в чате и не выводи его содержимое. Голосовые сообщения
   и аудио не подключай. Защити данные и ограничь этого бота владельцем, Gateway — loopback.
   Сохрани другие аккаунты и каналы действующего OpenClaw. Если помощника нельзя
   изолировать без изменения их доступа, предложи отдельный экземпляр и дождись выбора.

8. Только для выбранной Telegram-ветки: подготовь локальную установку по dry-run в новую папку, персонализируй только
   подтверждённые мной поля. Если обязательные поля Telegram-контекста не определены,
   не придумывай их для валидатора: уточни либо оставь режим по запросу. Перед изменением существующей конфигурации создай backup.
   Если помощник уже установлен, используй описанный side-by-side upgrade, сохрани
   журнал, останови старых писателей перед переключением и не дублируй задания.
   Контекст Claude и OpenClaw имеют разные схемы: назначь источник истины и опиши
   явное соответствие полей; не направляй оба процесса на один JSON/журнал.
   Установщик создаёт декларации, но не запускает бота или расписание.
   Покажи фактические времена в моём часовом поясе и состав подключаемых источников.
   Включай расписание и отправляй один тест только после моего выбора активировать
   эту настройку; если я уже дал такое разрешение, не спрашивай повторно.
   Десятку в Telegram включай лишь с рабочим процессом подготовки и импорта:
   один флаг не создаёт генератор. Без подготовленной подборки не выдумывай сообщение;
   вечернее ретро должно оставаться доступным независимо от неё.

9. Проверь копирование скиллов, JSON, сохранность исходного CLAUDE.md вне блока,
   приватность путей и отсутствие личных данных в Git. Для Telegram запусти тесты
   пакета и verify.py, затем отдельно проверь загрузку плагина, эффективную конфигурацию,
   единственность расписаний, реальную доставку и одну запись события без дубля.
   Используй синтетические данные для тестов; не заполняй ими мой живой журнал.
   Если внешняя интеграция недоступна, заверши независимую локальную часть и точно
   укажи, что остаётся ненастроенным. Не называй dry-run работающим ботом.

10. Оставь мне короткую инструкцию: как начать утро, записать идею/успех/состояние,
    провести вечер и неделю, где лежат мои данные, как выключить расписание,
    сделать backup и обновиться без потери истории. Запиши версии, выбранные модули,
    пути и результаты проверок в приватный setup-report.md без секретов.
    В финале отдельно перечисли: работает и проверено; настроено, но ещё не проверено;
    не подключено по моему выбору. Продолжай самостоятельную работу в согласованном
    объёме, спрашивая только о значимых личных выборах и недостающих разрешениях.
```
