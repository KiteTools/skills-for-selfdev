# Оригинальные иллюстрации

[English](README.md) · [Русский](README.ru.md)

Главная иллюстрация, схема цикла и четыре иллюстрации разделов созданы для этого репозитория. В них нет скриншотов, личных данных, чужой игровой графики или встроенных исходных растровых материалов. Рядом с PNG-версиями для GitHub Markdown лежат редактируемые оригиналы SVG.

Палитра: тёплая бумага, угольный, фиолетовый и мягкий зелёный. Текст остаётся частью SVG, чтобы его можно было редактировать. PNG-копии обеспечивают предсказуемое отображение в GitHub и в предпросмотре при отправке ссылок.
