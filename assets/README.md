# Original illustrations

[English](README.md) · [Русский](README.ru.md)

The hero, cycle diagram, and four collection illustrations were created for this repository. They contain no screenshots, personal information, third-party game artwork, or embedded raster source material. Editable SVG originals accompany PNG renders used by GitHub Markdown.

Palette: warm paper, charcoal, violet, soft green. Text is part of the SVG for editability. The PNG copies provide predictable rendering in GitHub and sharing previews.

## Disco atlas

[`voices-atlas.webp`](../skills/disco-mirror/assets/voices-atlas.webp) contains original ImageGen illustrations made for Disco Voices, visual revision 0.4.2 dated 22 August 2026. 24 images, 3072 × 2048. Only the shared atlas is included; personal builds and interview results are excluded. The illustrations were not extracted from the game.

The `system-map` diagram is also supplied as editable SVG and PNG, in Russian and English.
