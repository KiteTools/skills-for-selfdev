# Начни с одного полезного результата

**Для Claude Code:** [собери ежедневного помощника — готовый промпт и карта компонентов](guides/daily-assistant-claude-code.ru.md).

[English](getting-started.md) · [Русский](getting-started.ru.md)

Выбери скилл в [каталоге](catalog.ru.md). Прежде чем передавать личный материал, прочитай, что нужно на входе, какой будет результат и какие есть требования.

## Если нужен личный ассистент

Начни с [карты системы](system-map.ru.md). Для контекста и правил работы достаточно установить `personal-codex-assistant`. Добавляй `evening-ten` и `weekly-review`, когда понадобятся эти практики. Для GoR есть отдельный `reflect-on-reaction`.

```sh
python3 scripts/install.py personal-codex-assistant evening-ten weekly-review
```

`personal-daily-assistant` — следующий, необязательный слой с программой и сервисами. Копирование этого скилла ещё не устанавливает runtime и не включает Telegram. Порядок обновления существующего помощника описан на [его странице](skills/personal-daily-assistant.ru.md).

## Установить отдельный скилл

Требования: Git и Python 3.10 или новее для установщика. Твой AI-ассистент должен поддерживать скиллы либо принимать выбранные инструкции в виде файла.

```sh
git clone https://github.com/KiteTools/skills-for-selfdev.git
cd skills-for-selfdev
python3 scripts/install.py --list
python3 scripts/install.py learning-notes
```

Папка по умолчанию — `~/.agents/skills/`, один из поддерживаемых Codex каталогов пользовательских скиллов. Чтобы выбрать папку проекта или каталог, поддерживаемый другим агентом:

```sh
python3 scripts/install.py learning-notes --dest /path/to/project/.agents/skills
```

Установщик копирует скилл целиком, включая связанные материалы и скрипты. Он отказывается перезаписывать существующую папку скилла, не допускает символические ссылки внутри скилла и папку назначения, которая сама является символической ссылкой. Для обновления сначала просмотри изменения и самостоятельно перемести старый скилл в другое место, затем установи новую версию. Устанавливать всю коллекцию необязательно:

```sh
python3 scripts/install.py --all
```

Копирование скилла не запускает его внутренний установщик, не включает сервисы, не меняет расписания и не передаёт данные. Первый запуск лучше вызвать явно:

```text
Используй $learning-notes с приложенным транскриптом. Пиши на моём языке.
Сохрани примеры и отметь всё, чего источник не подтверждает.
```

Если новый скилл не появился в Codex, перезапусти приложение. У других агентов могут отличаться папки поиска и синтаксис вызова; смотри их документацию. Файл `SKILL.md` можно передать и просто как инструкцию, но отсутствующих инструментов у агента от этого не появится.

## Упаковка в плагин

Корневой `plugin.json` объединяет те же скиллы в переносимом формате плагина. `.codex-plugin/plugin.json` — манифест совместимости с Codex. Используй приложение, которое умеет импортировать этот источник плагина; репозиторий не заявляет присутствия в официальном магазине. Установка отдельных скиллов выше — явный и воспроизводимый способ начать работу.

Смотри официальную [документацию скиллов](https://developers.openai.com/codex/skills/) и [формат плагинов](https://developers.openai.com/plugins/build/plugins).

## Что требует дополнительной настройки?

| Процесс | Дополнительные требования |
| --- | --- |
| Рефлексия, конспекты, очистка, вечерняя десятка, события жизни, Disco | AI-ассистент и предоставленный исходный материал |
| Отчёт по интервью эксперта | Python; браузер для визуальной проверки; независимые контексты анализа для полного разбора |
| Восстановление SVG | Возможность записать SVG и отрисовать его для сравнения |
| Необязательные плакаты по сессии | Инструмент генерации изображений; он не устанавливается автоматически |
| Личный ежедневный помощник | Python, Node.js, OpenClaw, Telegram-бот и частное локальное хранилище; смотри его контракт установки |
| Подготовка данных Longevity | Внешнее приложение; поддерживаемые инструменты связи агента с браузером для автоматической работы либо ручной ввод |
| Личный кабинет + SendPulse | Собственный развёрнутый Личный кабинет и настроенные аккаунты; смотри руководство по интеграции |

## Первые десять минут

1. Возьми короткий материал без чувствительных данных или вымышленный пример.
2. Попроси один результат на удобном тебе языке.
3. Сверь несколько утверждений с оригиналом.
4. Оставь полезное и исправь ошибки. Добавляй личный материал, когда станет понятно, куда идут данные.
