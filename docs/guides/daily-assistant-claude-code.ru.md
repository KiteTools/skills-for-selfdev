# Собери ежедневного помощника в Claude Code

[English](daily-assistant-claude-code.md) · **Русский**

Чтобы не начинать каждый день с чистого листа: помнить, что для тебя важно, выбирать свой следующий шаг и видеть, что получилось. Ты можешь начать с разговора и заметок в Claude Code. Telegram и сообщения по расписанию добавляются, когда тебе нужен такой ритм.

**[Скопировать готовый промпт для Claude Code →](../../prompts/setup-daily-assistant.claude.ru.md)**

Промпт поручает агенту изучить репозиторий, выяснить твои предпочтения, настроить выбранные компоненты и проверить результат. Личные данные автора не нужны. Агент не должен требовать от тебя готовую жизненную стратегию: начать можно с одного понятного фокуса.

## Какие запчасти за что отвечают

| Компонент | Польза | Что реально входит |
| --- | --- | --- |
| [Личный контекст](../skills/personal-codex-assistant.ru.md) | Помнить твоё направление и отмечать подтверждённые результаты | Инструкции, чистый JSON, шаблоны `AGENTS.md` и `CLAUDE.md`, необязательный журнал; без фоновой программы |
| [Ежедневный помощник](../skills/personal-daily-assistant.ru.md) | Утро, идеи, успехи, состояние, вечер в Telegram | Python runtime, OpenClaw-плагин, установка, проверка, обновление в соседнюю папку, тесты |
| [Вечерняя десятка](../skills/evening-ten.ru.md) | Увидеть новые возможности в прожитом дне | Скилл по запросу, контракт подготовленной подборки и импорт в помощник; без автоматического сборщика и генератора |
| [Недельное ретро](../skills/weekly-review.ru.md) | Сопоставить намерение, понимание, действия и результат | Разбор выбранных свидетельств, учёт пересечений и пробелов; по запросу |
| [Разбор реакции](../skills/reflect-on-reaction.ru.md) | Исследовать конкретный эпизод и своё понимание | Отдельная практика; не включается автоматически при низкой отметке состояния |
| [Разбор консультации](../skills/reflect-on-session.ru.md) | Сохранить принятые понимания и последующие наблюдения | Работа с предоставленным материалом; перенос в контекст требует твоего выбора |

Выпуск коллекции **0.3.0** обновляет утренний выбор, редакционный подход Десятки и сборку в Claude Code. Он не объявляет весь частный помощник готовым публичным продуктом. [Что обновлено и что осталось вне пакета](../release-0.3.ru.md).

## Как начать

Вставь промпт в Claude Code. Агент сохранит SHA выбранной версии и предложит приватную рабочую папку. Для ручной установки из корня скачанного репозитория:

```sh
python3 scripts/install.py personal-codex-assistant weekly-review \
  --dest /absolute/private/assistant/.claude/skills
```

Это пример пути: выбери свой. Установщик только копирует папки скиллов и отказывается перезаписывать существующие. Он не создаёт `CLAUDE.md`, контекст или Telegram-бота — эти шаги агент выполняет по инструкции. Название `personal-codex-assistant` сохранено для совместимости; устанавливать Codex не нужно. В Claude Code используй `/personal-codex-assistant` или явно попроси применить этот скилл. При необходимости начни новую сессию после установки.

Claude Code использует `.claude/skills/` и `CLAUDE.md`; корневой `plugin.json` этой коллекции не является готовым Claude-плагином. Официальные опоры: [скиллы](https://code.claude.com/docs/en/skills), [инструкции проекта](https://code.claude.com/docs/en/memory).

## Два контекста нельзя соединить простым переименованием

В режиме по запросу основной файл — `.personal-codex/context.json`; у OpenClaw — `context/active_context.json`. У них разные схемы и команды записи. Назначь один основной источник целей. Второй контекст обновляй только явным переносом выбранных значений с проверкой:

| Контекст агента | Контекст OpenClaw | Что проверить |
| --- | --- | --- |
| `l1` — строка | `l1.text` | Твои слова, без придуманной философии |
| `l2[]`, `period_focus` | `focus_groups[]` | Соответствие направлений, а не копирование JSON целиком |
| `tasks[]` | `task_choices[]` | ID, состояния и критерии результата; это не взаимозаменяемые массивы |
| `journal.jsonl` | Журнал runtime `events.jsonl` | Не объединять файлы: разные форматы событий и писатели |

Автоматического адаптера и двусторонней синхронизации здесь нет. Недельное ретро может читать выбранные записи из обоих источников с явным указанием происхождения.

Для режима по запросу неизвестные направления могут оставаться пустыми. Telegram runtime требует заполнить обязательные поля: направление, текущее понимание, срок фокуса, вопросы утра и вечера, группу фокуса и хотя бы один вариант задачи. Заполни их своими словами; если пока не хочешь определять эти значения, начни с режима по запросу. Агент не должен придумывать ответы ради прохождения проверки.

## Что ещё потребуется для Telegram

Свои бот и аккаунты, приватный файл токена, owner ID, часовой пояс, совместимый OpenClaw и постоянно работающая машина. Claude Code настраивает систему; сам по себе он не обеспечивает круглосуточную доставку и не даёт OpenClaw автоматически доступ к своей подписке.

Runtime поддерживает macOS/Linux. WSL на Linux-файловой системе предполагается подходящим, но отдельно не проверен; нативный Windows не поддерживается из-за POSIX-блокировок и прав. На Windows можно начать с контекста и скиллов в Claude Code, а Telegram разместить позже в выбранной поддерживаемой среде.

Настройка модели и возможная стоимость зависят от твоей конфигурации OpenClaw. Обычные сообщения по расписанию выполняются командными заданиями без вызова модели; подготовка Десятки — отдельная работа агента. Ни один установщик не включает расписание сам.

## Когда можно считать настройку готовой

Для Claude Code: скиллы найдены, твой контекст читается из выбранной папки, прежние инструкции сохранены, журнал пишет только после включения и явного ответа. Для Telegram дополнительно нужны подтверждённая доставка владельцу, запись ровно одного события и проверка действующих расписаний. `verify.py` проверяет файлы и часть конфигурации, но не доказывает живую доставку.

Локальные файлы, переданные агенту, становятся входом настроенного сервиса модели; Telegram — отдельный внешний канал. Не клади в публичный репозиторий ни контекст, ни журнал, ни токены.
