# СООВ: с чего начинался ввод событий жизни

[English](soov.md) · [Русский](soov.ru.md)

СООВ появился до Longevity. Его первый экран позволял собирать события жизни двумя способами: вводить вручную или извлекать из транскрипта. Такой вход полезен сам по себе — сначала собрать материал, а затем переходить к рефлексии или исследованию модели.

В этом репозитории есть [скилл «Лента событий»](../skills/life-events.ru.md) для обеих задач. Он сохраняет источники, приблизительные даты и собственную оценку человеком каждого события.

**Статус:** переносимый вспомогательный скилл, а не исходное приложение СООВ. Для этого релиза не установлены точное публичное расположение исходников СООВ, способ развёртывания и требования к авторизации. Пакет не включает его сервер и аккаунты; совместимость импорта не заявлена.

Отдельное публичное приложение с описанным вводом данных — [Longevity](../skills/longevity-intake.ru.md). Его условные расчёты и интерфейс WebMCP — следующий самостоятельный инструмент, а не обязательная часть простой ленты событий.

## Как сделать СООВ отчуждаемым

Первую версию предлагается сделать небольшим браузерным приложением: добавить событие вручную, импортировать проверенный черновик из транскрипта, поправить хронологию и выгрузить резервную копию. Данные хранятся на устройстве; облачный аккаунт для этого не нужен. При этом хранение в браузере требует явного экспорта и восстановления: очистка браузера может удалить записи.

Для извлечения событий сначала можно использовать уже опубликованный life-events в выбранном человеком AI-ассистенте. Прямое подключение API модели и синхронизацию добавлять отдельно. Локальное хранение событий не означает, что облачный ассистент обрабатывает транскрипт на устройстве.

**Это предложение, приложение ещё не выпущено.** В [плане отчуждаемости](portable-apps.ru.md#soov) описаны формат данных, авторизация и проверка готовности. Первый шаг — найти и проверить исходники прежнего СООВ, затем выбрать между выделением готового экрана и небольшой новой реализацией.
