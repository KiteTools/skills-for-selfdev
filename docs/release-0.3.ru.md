# Обновление помощника 0.3.0 · 2 октября 2026

[English](release-0.3.md) · **Русский**

Помощник теперь проще собрать под себя в Claude Code. Утро оставляет место твоему собственному выбору, а Десятка помогает выйти за рамки обслуживания уже начатых проектов.

## Что обновлено

- [Готовый промпт для Claude Code](../prompts/setup-daily-assistant.claude.ru.md) ведёт от проверки среды до проверки результата; различает режим по запросу и Telegram.
- [Карта компонентов](guides/daily-assistant-claude-code.ru.md) показывает, что ставить, что необязательно и где проходят границы совместимости.
- `personal-codex-assistant` поддерживает выбор между `AGENTS.md` и `CLAUDE.md`. Есть отдельный шаблон Claude; историческое имя скилла и формат контекста сохранены.
- Утренний Telegram-диалог принимает свободный выбор. Каталог открывается по «Показать задачи»; прежние номера, `0` и кнопки работают. Свободный выбор сохраняется один раз и не меняет каталог.
- Намерение «хочу, чтобы…» не запускает продолжение агентом автоматически. Явная просьба к агенту в начале сообщения распознаётся отдельным правилом; это не семантическое определение намерения.
- Десятка рассматривает новые способы участия в происходящем и показывает связь наблюдения с предлагаемой возможностью. Частные квоты, убеждения и отношения автора не стали универсальными настройками.
- Исправлен маршрут установки для Windows: контекст и скиллы доступны отдельно; Telegram runtime требует POSIX-среду. WSL пока не проверен.

## Что уже было и сохранено

Локальный журнал, идеи и успехи, явные сообщения о занятиях, импорт подготовленной Десятки, неизменные номера её пунктов, отдельные отклики и обновление в соседнюю папку. Недельное ретро уже умеет использовать выбранные решения разбора реакции как решения, не приписывая им совершённые действия.

## Что найдено в частной системе, но не выдано за готовую публичную часть

| Механизм | Публичная граница |
| --- | --- |
| Сбор дня из Computer History, RescueTime, ActivityWatch и работы агентов | Общий сборщик и автоматическое подключение устройств не поставляются. Скиллы могут разбирать предоставленные сводки |
| Сортировка смысловых занятий по времени человека, отдельный учёт машины | Правила анализа отражены в промпте; поля частного `day_activities` не добавлены в API runtime |
| Подготовка Десятки перед 22:00 | Поставляется скилл и импорт; фоновый генератор требует отдельной настройки |
| Расширенные команды фиксации и дополнения отметок состояния | В этом выпуске не переносились; публичный журнал использует свои существующие команды и формат коррекций |
| Личный куратор, автоматический GoR, аудио, дашборд и синхронизация внешних задач | Не входят в публичную сборку; это не скрытые зависимости для запуска |

## Обновление без потери своего контекста

Сохрани свои изменения и сравни новую версию с установленной. Корневой установщик не перезаписывает скиллы. Для действующего Telegram-помощника следуй [контракту обновления](../skills/personal-daily-assistant/references/installation-contract.md#supported-hosts-and-safe-upgrade): новая соседняя папка, остановка прежних писателей перед переключением, backup, сохранение данных и проверка расписаний. Замена скилла не обновляет работающий runtime.

Форматы контекста Claude/Codex и OpenClaw остаются разными. Автоматической синхронизации и переноса старого частного архива одним запуском нет. Агент должен проверить совместимость прежней установки до использования `upgrade.py`; если исходные метаданные не подходят, сохранить рабочую систему и составить явный перенос.

## Проверка

В поставку входят синтетические проверки свободного выбора, открытия каталога, номеров и `0`, повторной доставки, устаревших кнопок, восстановления диалога и отсутствия автоматического исполнения намерения. В CI запускаются проверки коллекции, установки, runtime и транспорта.

Инструкции для Claude сверены с официальными [скиллами](https://code.claude.com/docs/en/skills) и [CLAUDE.md](https://code.claude.com/docs/en/memory). Копирование в `.claude/skills/` проверяется локально. Живая настройка чужого Claude Code, Windows/WSL и нового Telegram-бота этим выпуском не заявляется проверенной.
