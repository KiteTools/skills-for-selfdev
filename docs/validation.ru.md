# Проверки и ограничения релиза

[English](validation.md) · [Русский](validation.ru.md)

Версия 0.2.0 связывает самостоятельные практики с личным контекстом и ежедневным помощником. Для полезного релиза важно прямо описать, что проверено, а что по-прежнему зависит от твоего окружения.

## Проверки пакета

- Тринадцать входных файлов скиллов проверены валидатором метаданных в начале файла.
- Манифест совместимости с Codex проверен валидатором плагинов.
- Относительные Markdown-ссылки, названия скиллов, версии манифестов и структура SVG проверены через `scripts/check_repo.py`.
- Публичные файлы просмотрены на наличие частных исходных записей, персональных путей автора, учётных данных и примеров, позволяющих узнать человека. Автоматический поиск дополняет эту проверку, но не может доказать анонимность произвольного текста.
- Просмотрены отрисованные оригинальные иллюстрации и предпросмотр Markdown в стиле GitHub. Английская и русская главные страницы, каталог и страница одного скилла отрисованы на широкой и узкой ширине. Это проверка представления содержимого, а не всех клиентов GitHub.

На локальной проверке 0.2.0 прошли **224 автоматических теста**: 201 Python и 23 Node. Дополнительно проверены копирование всех 13 скиллов и отказ повторной установки, импорт и отклики Десятки через CLI, а также однократная доставка при конкурирующих запусках и остановка после неопределённой доставки. Использовались вымышленные данные и имитация транспорта; живых сообщений не отправляли.

## Воспроизводимые тесты

Запускай из корня репозитория. Нужны Python 3.10+ и Node.js; процесс GitHub проверяет Python 3.10 и 3.12 с Node.js 22.

```sh
python3 scripts/check_repo.py
python3 -m unittest discover -s tests -v
python3 -m unittest discover -s skills/analyze-expert-interview/tests -v
python3 -m unittest discover -s skills/reconstruct-svg/tests -v
python3 -m unittest discover -s skills/personal-daily-assistant/tests -v
python3 -m unittest discover -s skills/personal-daily-assistant/assets/runtime/tests -v
node --test skills/personal-daily-assistant/assets/runtime/openclaw-plugins/personal-daily-transport/test/*.test.mjs
```

Тесты установки проверяют копирование, отказ перезаписывать пользовательские изменения, недопустимые названия и обработку символических ссылок. Тесты интервью охватывают разбор текста, метрики, цитаты, происхождение выводов, отрисовку и необязательный строгий контракт оценки. Тесты SVG проверяют векторную структуру. Тесты помощника проверяют контракт установки, поведение журнала и диалога, маршрутизацию и учёт доставки на синтетических данных и имитациях сервисов.

[История GitHub Actions](https://github.com/KiteTools/skills-for-selfdev/actions) — актуальная запись удалённых тестов. Успешный запуск относится к конкретному коммиту, а не к более поздней правке или настроенному работающему сервису.

## Пробные запуски и визуальные проверки

В независимой пробе скилл «Вечерняя десятка» применили к предоставленному вымышленному дню. Получилось двадцать кандидатов и десять выбранных возможностей с охватом всех трёх линий исходного материала. Отсутствие истории предыдущих предложений отмечено явно. Это одна проба, а не оценка на разных моделях.

Вымышленный SVG-пример отрисован и сопоставлен с источником. Пример интервью прошёл через парсер и расчёт метрик. Полный смысловой отчёт по транскрипту реального человека для этого релиза не создавался.

Для версии 0.2.0 проведены независимые пробы на вымышленных данных: недельное ретро с пересекающимися сводками, поправкой об офлайн-событии и незавершённой работой; GoR с отказом от предложенной причины, светской рамкой и запретом сохранения. В этих пробах сохранились пробелы, несогласие и различие решения и выполнения. Это отдельные сценарии, не статистическая оценка качества.

Отдельная пробная настройка ассистента Codex выполнена в вымышленной временной папке: прежние инструкции вне добавленного блока и существующий контекст сохранились, повторная настройка не создала дубликат, выключенный журнал не появился, обсуждение не закрыло задачу.

Новая карта, главные страницы EN/RU и страница Disco проверены в локальном Markdown-предпросмотре на ширинах 1440 и 390 px: изображения загружаются, переполнения страницы нет. Атлас Disco проверен отдельно; EXIF/XMP/IPTC-метаданных нет.

## Чего эти проверки не подтверждают

- Точность или психологическую обоснованность каждой интерпретации, созданной моделью.
- Медицинскую обоснованность условной модели жизни.
- Совместимость с любым AI-приложением, версией OpenClaw или операционной системой.
- Работающее соединение с Telegram, включённые расписания или успешную живую доставку на твоём компьютере.
- Живую интеграцию Личного кабинета с SendPulse на новых аккаунтах или совместимость СООВ со старым форматом данных. Отдельные приложения публикуют свои тесты в собственных репозиториях.
- Качество новых изображений и отчётов, созданных в следующей пользовательской сессии без просмотра результата.

Личный помощник развивает августовскую переносимую основу отдельными проверяемыми модулями; это не копия всей частной системы автора. Диалоги преимущественно на русском языке. Настройка работающих сервисов остаётся отдельным явно запрошенным шагом. Храни частные рабочие данные вне этой копии репозитория.
