# Голосовая фраза в дыхательном MP3

[English](embed-breath-voice.md) · **Русский**

Добавь свой вопрос или короткое напоминание в нужный момент практики. Ты выбираешь фразу, голос и время; скилл создаёт новый MP3, мягко приглушая фон на время голоса. **Исходный файл остаётся неизменным. Muse не обязателен** — нужен только выбранный тобой MP3.

## Что ты передаёшь и получаешь

Передай исходный MP3, точку вставки и точную фразу. Можно синтезировать голос через ElevenLabs или использовать уже записанную реплику. Один запуск добавляет одну вставку. На выходе — новый MP3 и JSON с путём, временем вставки, длительностями и выбранным голосом.

Фон снижается до 18% во время реплики, с переходами по 0,3 секунды. Начало трека не сдвигается. Если реплика выходит за конец исходника, новый файл продолжается до её окончания. Для нескольких вставок последовательно используй предыдущий результат как вход, каждый раз выбирая новое имя файла.

## Что установить

- **Node.js 22 или новее**. Дополнительные npm-пакеты не нужны.
- **ffmpeg и ffprobe** в PATH; сборка ffmpeg должна включать кодировщик `libmp3lame`.
- Для синтеза — свой аккаунт ElevenLabs и переменная окружения **`ELEVENLABS_API_KEY`**. С готовой голосовой записью ключ и аккаунт не нужны.

Проверь окружение: `node --version`, `ffmpeg -version`, `ffprobe -version`. При необходимости установи Node.js и ffmpeg средствами своей системы. Скилл сам программы не устанавливает и аккаунты не подключает.

Из корня скачанного репозитория установи скилл в приватный проект Claude Code:

```sh
python3 scripts/install.py embed-breath-voice --dest /absolute/private/project/.claude/skills
```

Для Cursor замени папку назначения на `.cursor/skills` своего проекта; для другого агента выбери его папку скиллов. Python нужен только этому установщику: можно вручную скопировать всю папку [embed-breath-voice](../../skills/embed-breath-voice), а скрипт запускать через Node.js.

## Попробуй

С готовой голосовой записью, из корня репозитория:

```sh
node skills/embed-breath-voice/scripts/embed-voice.mjs \
  --input /absolute/private/breathing.mp3 --at 12:05 \
  --voice-file /absolute/private/question.mp3 \
  --output /absolute/private/breathing-with-voice.mp3
```

Для синтеза сначала задай свой ключ в окружении терминала, не записывая его в Git или переписку. Затем:

```sh
node skills/embed-breath-voice/scripts/embed-voice.mjs \
  --input /absolute/private/breathing.mp3 --at 12:05 \
  --text "Что сейчас для меня важно?" --voice male \
  --output /absolute/private/breathing-with-voice.mp3
```

Замени пути и время на свои. Поддерживаются секунды, `мм:сс` и `ч:мм:сс`. Папка результата должна существовать, имя файла — быть новым. Без `--output` результат появится рядом с исходником с суффиксом `_voice_12-05.mp3`. Если файл уже есть, скрипт остановится, включая случай символьной ссылки на исходник.

`--voice` принимает `male`, `female`, `мужской`, `женский` или ID доступного тебе голоса ElevenLabs. Встроенные ID сохранены из исходного скилла; доступность в твоём аккаунте нужно проверить. Модель — `eleven_multilingual_v2`. [Описание API ElevenLabs](https://elevenlabs.io/docs/api-reference/text-to-speech/convert).

## Запрос своему агенту

> Вставь фразу «Что сейчас для меня важно?» в мой дыхательный MP3 на 12:05 мужским голосом. Примени embed-breath-voice, сохрани исходник и создай отдельный файл. Если не хватает пути или доступа к синтезу, уточни только недостающее.

В режиме синтеза текст отправляется в ElevenLabs и расходует квоту твоего аккаунта. Сам дыхательный MP3 смешивается локально. Режим `--voice-file` не обращается к ElevenLabs. Не публикуй личные записи, ключи и результаты без отдельного решения.

## Проверки и границы

Тесты используют только синтетические звуковые сигналы: проверяют время вставки, приглушение и восстановление фона, сохранность исходников, запрет перезаписи и обработку ошибок. Запрос синтеза проверен с локальной подменой ответа API; живой вызов и доступность голосов в твоём аккаунте этим не подтверждаются. Проверки выполняются на macOS локально и Linux в CI; Windows отдельно не проверен.

После создания послушай участок вокруг вставки и оцени разборчивость. Скилл не определяет дыхательные фазы, не работает с EEG и не оценивает пользу практики. Аудиозаписи в пакет не входят.
