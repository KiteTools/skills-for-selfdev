# Learning notes

![Skills for Selfdev: source-grounded learning, readable transcripts, editable diagrams, and interview review](../../assets/learn.png)

**Keep the explanation you can return to, not just a list of highlights.**

This skill turns a lecture or workshop transcript into study notes that preserve definitions, causal reasoning, examples, and the speaker's uncertainty. It can improve an existing draft or start from the transcript alone.

| | What to expect |
| --- | --- |
| Input | Full transcript; optional draft notes, glossary, or source manual |
| Output | Markdown study notes with source anchors; coverage map when needed |
| Useful for | Revisiting a course, preparing for a study group, finding questions to ask |
| Requirements | An AI assistant that reads Markdown and local text files |
| Status | Installable instruction skill; fictional input/output example included |

## Try it

> Use learning-notes on this workshop transcript. Preserve the examples and qualifications. Separate what the speaker taught from any study questions you generate. Save notes with source anchors.

[Open the fictional example](../../examples/learning-notes/) · [Read the skill](../../skills/learning-notes/SKILL.md)

## What makes it useful

The skill checks draft coverage instead of quietly dropping awkward points. A source manual can resolve notation without expanding the course into a different lesson. Contradictions and uncertain words remain visible for review.

It does not certify understanding, silently rewrite your knowledge base, or add outside research. You choose whether to turn the notes into a study or practice plan.
