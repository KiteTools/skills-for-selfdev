# Clean transcript

**English** · [Русский](clean-transcript.ru.md)

![Skills for Selfdev: source-grounded learning, readable transcripts, editable diagrams, and interview review](../../assets/learn.png)

**Turn noisy recognition into readable speech without losing what was said.**

An automatic transcript can be difficult to follow even when its ideas are good. This skill removes transcription noise, restores punctuation, and checks terminology against an optional glossary while retaining the speaker's voice and sequence.

| | What to expect |
| --- | --- |
| Input | A raw text transcript; optional domain glossary |
| Output | Readable Markdown transcript and unresolved-term review |
| Useful for | Lectures, recorded reflections, interviews, and workshops |
| Requirements | An AI assistant that reads local text; audio transcription is separate |
| Status | Installable instruction skill; fictional before/after example included |

## The boundary that matters

A cleaned transcript is still speech. Summarizing it, improving the argument, or inserting a later definition can change the source. This skill keeps those operations separate and leaves ambiguity visible.

Your glossary stays yours. The repository contains no private terminology corpus and the skill requires no account or automatic upload. Your chosen assistant's data handling still applies.
