# Очистка транскрипта

[English](clean-transcript.md) · **Русский**

![Skills for Selfdev: конспекты с опорой на источник, читаемые транскрипты, редактируемые схемы и разбор интервью](../../assets/learn.ru.png)

**Сделайте распознанную речь читаемой, сохранив то, что было сказано.**

Автоматический транскрипт бывает трудно читать даже тогда, когда само объяснение удачное. Скилл убирает шум распознавания, восстанавливает пунктуацию и сверяет термины с вашим словарём, если он есть. Голос говорящего и последовательность изложения сохраняются.

| | Что ожидать |
| --- | --- |
| На входе | Сырой текстовый транскрипт; по желанию — словарь терминов |
| На выходе | Читаемый транскрипт в Markdown и список мест, требующих проверки |
| Когда полезно | Обработка лекций, записанных размышлений, интервью и мастер-классов |
| Что нужно | ИИ-ассистент, который читает локальный текст; распознавание аудио выполняется отдельно |
| Статус | Скилл с инструкциями, доступный для установки; приложен вымышленный пример до и после обработки |

## Где проходит граница редактуры

Очищенный транскрипт остаётся записью речи. Пересказ, улучшение аргумента или вставка более позднего определения могут изменить содержание источника. Скилл разделяет эти операции и сохраняет неоднозначные места для проверки.

Вы используете собственный словарь. В репозитории нет частного корпуса терминов; скилл не требует аккаунта или автоматической загрузки файлов во внешний сервис. При этом к обработке данных по-прежнему применяются условия выбранного вами ИИ-ассистента.
