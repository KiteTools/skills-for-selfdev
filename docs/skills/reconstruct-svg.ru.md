# Реконструкция рисунка в SVG

[English](reconstruct-svg.md) · **Русский**

![Skills for Selfdev: конспекты с опорой на источник, читаемые транскрипты, редактируемые схемы и разбор интервью](../../assets/learn.ru.png)

**Сделайте полезную схему редактируемой, сохранив её смысл.**

Скилл восстанавливает сфотографированный набросок или рисунок из PDF в чистом векторном виде. Стрелки, связи, обозначения и подписи сверяются с оригиналом, а готовый результат проходит визуальное сравнение.

![Вымышленный пример векторной реконструкции; подписи на английском](../../examples/reconstruct-svg/figure.svg)

| | Что ожидать |
| --- | --- |
| На входе | Изображение или указанная страница PDF |
| На выходе | Самостоятельный SVG-файл и отчёт о соответствии оригиналу |
| Когда полезно | Учебные схемы, наброски с мастер-классов, редактируемые материалы для учёбы |
| Что нужно | Просмотр изображений; рендерер PDF для страниц PDF; рендерер SVG для визуальной проверки; Python 3 для встроенной структурной проверки |
| Статус | Скилл с инструкциями, проверенным структурным валидатором и оригинальным вымышленным примером |

## Сначала соответствие, затем оформление

Удачные отступы облегчают чтение. Но если превратить пересечение линий в соединение, изменится сама идея. Такие различия проверяются отдельно. Проверка XML подтверждает корректность векторного файла, но не его смысловую точность, поэтому визуальная сверка имеет собственный статус.

Это процесс векторной реконструкции. Он не включает Prism и не обещает восстановить измеренные данные по приблизительному наброску.
