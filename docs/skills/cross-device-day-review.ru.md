# Анализ дня по всем девайсам

[English](cross-device-day-review.md) · **Русский**

**Увидеть, чем на самом деле наполнился твой день.** Сопоставить планы с тем, чему ты уделил время, заметить возвращающиеся занятия и прийти к вечернему разговору с конкретными фактами. На этой основе легче понять происходящее, осмыслить неделю и поддержать выбранный фокус.

![Синтетический пример: пересечения устройств объединены, работа агента показана отдельно](../../assets/cross-device-day-review.svg)

Компьютер, телефон, заметки и работа агентов оставляют разные следы одного дня. Этот скилл помогает собрать их в понятную сводку. В первой открытой версии ты или твой агент готовите проверенный JSON из выбранных материалов; локальная программа выполняет расчёт. Автоматического подключения всех устройств здесь пока нет.

## Что ты получишь

- Перечень занятий по известной длительности; занятия без времени остаются в конце с пометкой «неизвестно».
- Объединённое время по записям человека и устройств: пересечения считаются один раз.
- Отдельный раздел машинной работы: сумма времени завершённых заданий и интервал их одновременной работы.
- Видимые пробелы: отсутствующий экспорт не превращается в ноль.
- Сопоставление с направлениями, которые выбрал ты, без автоматической оценки продуктивности.
- Markdown-отчёт, полный JSON и компактный JSON для дальнейшего разбора.

Встреча и заметки во время неё могут быть одним занятием. Для этого при подготовке данных им задаётся общий идентификатор эпизода. Программа не угадывает смысл окон и не решает за тебя, что является одним событием.

## Попробуй на вымышленном дне

Нужен Python 3.10+ с базой часовых поясов IANA. Дополнительные Python-библиотеки, API-ключи и аккаунты для CLI не нужны. Из корня репозитория:

```sh
python3 skills/cross-device-day-review/scripts/day_review.py \
  --config skills/cross-device-day-review/examples/config.json \
  --input skills/cross-device-day-review/examples/day.json \
  --output-dir /tmp/my-new-day-report
```

Выбери существующую приватную родительскую папку и новое имя результата: CLI не перезаписывает готовые отчёты. Пример полностью синтетический. В нём получится **140 минут** по доступным человеческим/устройственным интервалам; работа агента — **90 минут** суммарно и **60 минут** объединённого интервала. Эти числа не складываются. Отсутствующий планшет и неизвестная длительность разговора делают отчёт частичным.

Для установки скилла:

```sh
python3 scripts/install.py cross-device-day-review
```

Для Claude Code укажи приватный проект:

```sh
python3 scripts/install.py cross-device-day-review --dest /absolute/private/project/.claude/skills
```

Установщик копирует весь скилл; сбор данных и расписание не включает. [Контракт входа](../../skills/cross-device-day-review/references/input.md), [границы адаптеров](../../skills/cross-device-day-review/references/adapters.md), [чистый конфиг](../../skills/cross-device-day-review/examples/config.json) и [JSON-схема](../../skills/cross-device-day-review/references/input.schema.json) входят в папку скилла.

Чтобы передать скилл отдельным архивом, выполни из корня репозитория `python3 scripts/build_cross_device_package.py --output /tmp/cross-device-new.zip`. Сборщик берёт только файлы из явного списка поставки, добавляет контрольные суммы и проверяет содержимое готового ZIP. Выходной файл должен быть новым.

## Запрос своему агенту

> Примени cross-device-day-review к выбранным мной материалам дня. Подготовь приватный нормализованный JSON, сохрани происхождение записей и применённые поправки. Объедини подтверждённые записи об одном занятии, не прибавляй машинное время к моему. Запусти CLI, затем помоги осмыслить результат и уточни только значимые пробелы. Не подключай новые источники и не публикуй отчёт.

Если ты исправил время встречи, агент должен **заменить прежние границы в подготовленных записях**, сохранив поправку в приватной заметке. Добавить новую запись рядом со старой недостаточно: CLI объединяет интервалы и не определяет автоматически, какая версия верна.

## От фактов к пониманию

После проверки сводку можно передать в [недельное ретро](weekly-review.ru.md), использовать для [Десятки](evening-ten.ru.md) или обсудить с [личным ассистентом](personal-codex-assistant.ru.md). Это следующий отдельный шаг: программа не создаёт задачи, не оценивает твоё состояние и не отправляет данные в Telegram.

## Возможности и границы

Название описывает совместный разбор данных с разных устройств. Поставляется адаптер **нормализованного JSON**. Для ActivityWatch, RescueTime, Computer History, календаря и агентов есть инструкция подготовки; готовых сетевых коннекторов в этом выпуске нет. Агрегат «120 секунд внутри пяти минут» нельзя превращать в выдуманный точный интервал. Пока точных границ нет, длительность остаётся неизвестной, а исходная оценка — в приватной заметке.

Программа видит только переданные записи. Активное приложение не доказывает внимание или понимание. Длительности отдельных занятий могут пересекаться, поэтому их сумма не является итогом дня. Даже статус `ready` означает готовность выбранного экспорта, а не непрерывное наблюдение суток.

Код и примеры проверяются локальными тестами и CI. Живые подключения сервисов, Windows/WSL и полнота реального дня этим не подтверждаются. Нормализация не гарантирует обезличивания: храни свои подписи, заметки и отчёты вне публичного Git и проверяй их перед передачей модели или другому человеку.
