# Персональный ассистент Codex

[English](personal-codex-assistant.md) · **Русский**

![Ритм, соединяющий личный контекст, работу и осмысление результата](../../assets/rhythm.ru.png)

**Сохраняйте связь с выбранным направлением, пока Codex помогает делать конкретную работу.**

Вы открываете задачу, чтобы закончить небольшой прототип. Ассистент коротко связывает ожидаемый результат с вашим фокусом, помогает выполнить работу, проверяет результат и спрашивает, как вы прожили этот процесс. Ответ можно сохранить в личном журнале. Трудное переживание не отменяет выполненной работы, а хорошее самочувствие не доказывает, что задача завершена.

Этот самостоятельный скилл переносит правила личного контекста в Codex. Для него не нужны Telegram-бот, OpenClaw или другие установленные скиллы.

## Что он делает

| Момент | Конкретный результат |
| --- | --- |
| Настройка | Пустой личный контекст и аккуратно добавленный блок инструкций для одной выбранной рабочей папки |
| Начало задачи | Одна строка, связывающая главное направление, подходящую цель, текущий фокус и ожидаемый результат |
| Подтверждённое выполнение | У соответствующей задачи в каталоге появляются доказательство и статус выполнения, если вы ведёте каталог |
| После работы | Необязательный вопрос о жизнеспособности; ответ сохраняется только при включённом локальном журнале |

L1 — ваше главное направление. L2 — конкретный способ двигаться в нём. Фокус периода — то, что важно сейчас. Эти смыслы задаёте вы: ассистент не выбирает за вас убеждения, жизненные цели или приоритеты. Задачи вне фокуса разрешены; он просто отмечает это.

Пять вариантов оценки жизнеспособности: **−− / − / = / + / ++**. Это ваше описание пережитого, а не автоматически рассчитанный балл. Ассистент спрашивает один раз после проверенной реализации, но не после обсуждения, сообщения о ходе работы или незавершённой попытки. Можно не отвечать или отключить вопрос. Стратегические выводы остаются для отдельно запрошенного недельного ретро.

## Попробуйте

```text
Используй $personal-codex-assistant, чтобы подготовить личный рабочий контекст
для выбранной мной приватной папки. Сохрани существующие инструкции AGENTS.
Перед настройкой покажи предлагаемый блок с ограниченной областью действия
и пустой контекст. Локальный журнал пока не включай.
Главное направление и текущий фокус есть в приложенных мной заметках.
```

**Вход:** выбранная рабочая папка, существующие инструкции и те направления, цели или текущий фокус, которыми вы хотите поделиться. Неизвестные значения остаются пустыми. **Выход:** предложенная либо уже разрешённая локальная настройка, строка согласования задачи с фокусом, обновления задач по доказательствам и необязательные записи личного журнала.

После настройки обычный запрос может выглядеть так:

```text
Помоги выполнить задачу sample-01 по её условию приёмки.
Учти мой текущий фокус, проверь результат и после работы спроси о жизнеспособности.
```

[Вымышленный пример](../../examples/personal-codex-assistant/example.ru.md) показывает контекст, границу фактического выполнения и ответ для журнала.

## Файлы и границы установки

В пакет входят [скилл](../../skills/personal-codex-assistant/SKILL.md), [пустой JSON-контекст](../../skills/personal-codex-assistant/assets/templates/context.json), [блок для AGENTS](../../skills/personal-codex-assistant/assets/templates/agents-block.md) и инструкции по [аккуратной настройке](../../skills/personal-codex-assistant/references/setup.md) и [записям журнала](../../skills/personal-codex-assistant/references/journal.md). Технические инструкции написаны на английском; ассистент отвечает на языке пользователя.

Предлагаемые пути внутри выбранной приватной папки — `.personal-codex/context.json` и необязательный `.personal-codex/journal.jsonl`. Существующий контекст сохраняется: настройка не сбрасывает его до шаблона. В AGENTS добавляется или обновляется только блок между специальными маркерами. Противоречащие инструкции и неоднозначные маркеры нужно разобрать до изменения. Глобальные настройки Codex не меняются.

Чтобы отключить правила, удалите этот блок или задайте `enabled: false` в контексте. Отключение журнала сохраняет прежние записи. Удаление данных, отправка сообщений и создание расписания автоматически не происходят.

## Требования, приватность и статус

Нужен Codex с доступом на чтение выбранных локальных файлов. Запись требуется только для разрешённой настройки, обновления каталога или ведения журнала. Пакету не нужны API-ключ, бот, база данных, Python или Node. Исполняемого установщика нет.

Храните контекст и журнал вне публичных репозиториев. Правило исключения Git не делает приватными данные, которые уже попали под контроль версий. Материалы, прочитанные в разговоре с Codex, могут передаваться настроенному сервису модели: локальные файлы не означают работу модели без сети. Журнал рассчитан на одного записывающего участника и не обещает фоновую синхронизацию или восстановление транзакций.

**Статус выпуска:** переносимые инструкции и чистые шаблоны для работы в Codex по запросу. Проверяются структура пакета и локальные ссылки; установка в живую среду, расписание и долгосрочный личный эффект не заявляются. Это отдельный модуль, отличный от [Personal Daily Assistant в Telegram](personal-daily-assistant.ru.md). [Карта системы](../system-map.ru.md) объясняет, как модули могут взаимодействовать, оставаясь самостоятельными.
