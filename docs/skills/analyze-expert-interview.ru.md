![Skills for Selfdev: конспекты с опорой на источник, читаемые транскрипты, редактируемые схемы и разбор интервью](../../assets/learn.ru.png)

**Увидьте, как устроено рассуждение внутри разговора.**

Можно хорошо знать тему и всё же потерять нить, объясняя её вслух. Скилл помогает гостю интервью увидеть карту своего выступления: темы, отступления, незаконченные рассуждения, сильные объяснения и конкретные места для улучшения. Выводы связаны с источником.

| | Что ожидать |
| --- | --- |
| На входе | Один транскрипт с явно обозначенными ролями HOST / GUEST, в формате TXT, SRT или VTT |
| На выходе | Автономный HTML-отчёт, нормализованный источник, метрики, файлы с доказательствами и статус проверки |
| Когда полезно | Разобрать своё интервью, улучшить учебную беседу, изучить аргументацию эксперта |
| Что нужно | Python 3.10+; ИИ-ассистент; независимые контексты для смыслового анализа; браузер для визуальной проверки |
| Статус | Рабочие парсер, расчёт метрик, рендерер и валидаторы связей с источником; есть регрессионные тесты. Смысловой анализ по-прежнему выполняет ассистент |

## Два разбора одного источника

Структурный проход отслеживает развитие разговора. Логический проверяет, как утверждения следуют из посылок и примеров. Раздельная работа снижает вероятность того, что первая возникшая интерпретация определит весь отчёт.

В отчёте есть карта тем, наблюдения о структуре, пробелы в рассуждениях, сильные места и пять обоснованных правок. Если короткий источник не даёт материала для пяти правок, результат ограничивается тем, что можно подтвердить, без выдуманных замечаний.

## Что подтверждают проверки

Встроенные Python-инструменты нормализуют роли говорящих, рассчитывают временные метрики, проверяют цитаты и их происхождение, затем собирают самостоятельный HTML-отчёт **на английском языке**. Они не определяют, насколько полезна сама критика, и не проверяют каждое утверждение по внешним источникам. Оценки темпа речи, слов-паразитов, влияния на аудиторию или личности здесь нет.

Дополнительный строгий протокол предусматривает трёх независимых рецензентов и свидетельства проверки в браузере. Его числовые пороги — договорённость о процедуре ревью, а не гарантия определённого процента правильности. Обычный процесс сообщает фактический статус проверки и не требует этого протокола.

## Запуск детерминированной части

Из корня репозитория:

```sh
python3 skills/analyze-expert-interview/scripts/parse_transcript.py \
  examples/analyze-expert-interview/interview.vtt /tmp/selfdev-normalized.json \
  --title "Fictional interview: choosing a weekly practice"
python3 skills/analyze-expert-interview/scripts/compute_metrics.py \
  /tmp/selfdev-normalized.json /tmp/selfdev-metrics.json
python3 -m unittest discover -s skills/analyze-expert-interview/tests -v
```

Если эти временные файлы уже существуют, выберите новые пути для результата. Для смысловых проходов ассистент должен прочитать транскрипт; один запуск парсера и расчёта метрик не создаёт проверенный аналитический отчёт.
