# Personal Daily Assistant: повседневный ритм с опорой на ваш контекст

[English](personal-daily-assistant.md) · **Русский**

![Иллюстрация повседневного ритма: утро, события дня, вечер и недельное ретро](../../assets/rhythm.ru.png)

Утром выбрать осмысленный следующий шаг, днём сохранить идеи и небольшие успехи, вечером осмыслить то, что действительно произошло. Этот пакет превращает такой ритм в личного текстового Telegram-ассистента на OpenClaw.

**Попробуйте:**

> Примени personal-daily-assistant: изучи мою среду и подготовь план частной установки. Помоги определить главное направление, текущий фокус и ежедневные вопросы. Перед включением расписания покажи пробный план без изменений.

## Что он делает

| Когда | Что происходит |
| --- | --- |
| Утром | Личный вопрос, напоминание о текущем фокусе и выбор следующих шагов |
| Днём | Короткие отметки жизнеспособности; сохранение идеи или успеха, пока они не забылись |
| Вечером | Обзор доступных сведений о дне, уточнение только пробелов и возвращение к незавершённым идеям |
| Раз в неделю | Обзор успехов, повторяющихся паттернов и собственная оценка человека |

Жизнеспособность здесь — опыт, о котором сообщает сам человек. Ассистент не выставляет эту оценку за него. Завершённый ответ агента также не закрывает автоматически жизненную задачу. В журнале различаются свидетельства, интерпретации и поправки.

## Что входит в пакет

- Детерминированный журнал и движок ежедневных диалогов на Python.
- Транспортный плагин OpenClaw с защитой от повторных ответов и восстановлением продолжений.
- Пустые шаблоны личного контекста, установщик с режимом предварительного просмотра и проверка установки.
- Тесты журнала, установки, маршрутизации, доставки и восстановления.

Это **переносимая версия за август 2026 года**, адаптированная для открытого распространения. Она не выдаётся за последнюю частную версию ассистента. Диалоги и команды фиксации событий преимущественно **на русском языке**; описания для посетителей доступны на русском и английском. Полной английской локализации диалогов нет.

## Что потребуется

Компьютер с macOS или Linux, Python 3.10+, Node.js и совместимая установка OpenClaw. Также нужны собственный Telegram-бот, закрытый файл с токеном, числовой Telegram ID владельца, часовой пояс IANA и отдельная частная рабочая папка. Дополнительный сбор активности Codex по умолчанию выключен. При явном включении он читает выбранные и проверенные экспорты транскриптов, включая фрагменты сообщений пользователя и ассистента. Это не сбор одних лишь метаданных, не запись экрана и не сервис Computer History.

Плагин использует OpenClaw plugin SDK и обработчики ответов и доставки. Совместимость конфигурации с установленной версией OpenClaw нужно проверить отдельно: репозиторий не закрепляет версию этого сервиса и не разворачивает его за вас. Доступ к Telegram, моделям и возможные расходы платформ остаются вашей ответственностью.

## Как установить

1. Скопируйте и заполните [шаблон контекста](../../skills/personal-daily-assistant/assets/templates/active_context.json). Замените все значения `REPLACE_WITH_YOUR_`. L1 — главное направление жизни; L2 — конкретный способ его воплощения; фокус периода — то, что важно сейчас.
2. Прочитайте [условия установки](../../skills/personal-daily-assistant/references/installation-contract.md), затем из корня репозитория посмотрите справку: `python3 skills/personal-daily-assistant/scripts/install.py --help`.
3. Запустите установщик с явными локальными путями. **Без `--apply` он только проверяет входные данные и выводит план.** Храните токен в файле, доступном только владельцу; не вставляйте его значение в запрос или аргумент командной строки.
4. Используйте `--apply` только для предназначенной под установку отдельной папки. Команда записывает локальные файлы и декларации конфигурации и расписания; сама по себе она **не запускает OpenClaw и не начинает отправку сообщений**.
5. Создайте резервную копию действующей конфигурации OpenClaw, подключите подготовленный фрагмент по схеме установленной версии и зарегистрируйте выбранные задания по одному разу. Удаление технических сообщений и архивирование задач по умолчанию выключены.
6. Запустите проверку установки и тесты. Затем, с разрешения владельца, проверьте одно текстовое сообщение в его личном чате. Сверьте доставленный ответ и сохранённое событие.

В шаблоне расписания: утро в 08:00, отметки в 12:00 / 15:10 / 18:00, вечер в 22:00 и недельный обзор в воскресенье в 20:00 — всё в выбранном часовом поясе. В 03:00 предусмотрено обновление контекста. Просмотрите эти задания перед включением. В этой версии нет отдельного более позднего правила «Десятка».

## Частными должны оставаться и файлы

Журнал событий хранится вне папки проекта с доступом только для владельца. Личный контекст, собранная активность и саммари тоже могут содержать чувствительные сведения: не публикуйте установленную рабочую папку и не добавляйте её в этот открытый репозиторий. В пакете нет настоящего журнала, ID контакта, токена бота или личной цели; данные тестов вымышлены.

Ни одно задание по умолчанию не сканирует историю Codex. Чтобы добавить активность, явно установите `PDS_INCLUDE_CODEX_ACTIVITY=1` и задайте абсолютный `PDS_CODEX_ACTIVITY_SOURCE_DIR` с экспортами, которые вы выбрали и проверили. Скрипт читает эти файлы и может включить в компактный контекст фрагменты сообщений, заголовки, рабочие каталоги и пути. Фильтрация по шаблонам не гарантирует анонимизации или удаления секретов. Этот контекст может попасть в Telegram-отчёт и контекст настроенной модели. Перед включением прочитайте [точное описание работы с данными](../../skills/personal-daily-assistant/references/installation-contract.md#optional-activity-data).

Сообщения Telegram и диалоги с моделью проходят через настроенные вами сервисы. Локальное хранение не делает эти каналы автономными. Встроенный ассистент принимает текст и нажатия встроенных кнопок; голосовые вложения он не расшифровывает.

## Проверка

Из корня репозитория:

```bash
python3 -m unittest discover -s skills/personal-daily-assistant/tests -v
python3 -m unittest discover -s skills/personal-daily-assistant/assets/runtime/tests -v
node --test skills/personal-daily-assistant/assets/runtime/openclaw-plugins/personal-daily-transport/test/*.test.mjs
```

Локальные автоматические проверки охватывают поставляемый пакет. Успешный запуск тестов не подтверждает, что ваш бот подключён, расписание включено или реальное сообщение доставлено.
