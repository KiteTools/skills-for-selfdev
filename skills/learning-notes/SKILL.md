# Learning notes

Create notes a learner can revisit and check against the source. This skill works with any subject; it does not supply a course doctrine or silently add textbook knowledge.

## Source contract

Read the whole transcript before drafting. If only an excerpt is available, label the result as notes on that excerpt. A draft is optional. When supplied, inventory its substantive points so none disappear without explanation. The transcript determines the content and the speaker's level of certainty. Use a supplied manual or glossary to check spelling, notation, quotations, and figure references; do not import new topics from it.

If a draft conflicts with the transcript, record the conflict and its location. Do not silently reconcile it or present the draft's unsupported claim as something taught. If the user asks for notes from a missing recording, request the source instead of reconstructing it from a title.

## Working method

1. Map the transcript into meaningful sections in the order taught. Within a section, combine repetition when this improves readability without changing the argument.
2. Write connected explanations: definition → distinction → reasoning → example → limitation, wherever the source supplies them. Preserve conditional language and distinguish an illustrative anecdote from a demonstrated general result.
3. Keep substantive learner questions when the instructor develops an answer. Do not promote an unendorsed learner answer to the instructor's position.
4. Quote only text that can be located in the supplied material. Give timestamps, paragraph IDs, or line references for important definitions, claims, examples, and unresolved points. Never invent timing or page numbers.
5. Finish with questions left open by the source and optional retrieval questions for the learner. Label questions as generated study aids, not quotes from the course. Proposed practice must be explicitly distinguished from exercises assigned by the instructor.
6. Check each draft point against the finished notes; check each substantial addition against the transcript. Preserve the original files and save the notes separately.

## Deliverable

Default to `learning-notes.md`: title, source scope, a short orientation, explanatory sections, key source anchors, and unresolved points. Add `coverage.md` when a supplied draft has material to reconcile or the source is long. This file maps draft points and transcript sections to the resulting notes, with explicit omissions and reasons.

Do not update a knowledge base or publish the notes unless requested. A clear summary is not evidence that the learner understood or adopted the material. At handoff report which source was covered and what still needs checking.
