# Optional visual reminders

The visual is a memory aid for an attributed session idea, not evidence for that idea. Use only beliefs and practice chains the user wants to revisit. Do not make a disputed formulation look settled by putting it in a polished diagram.

## Three posters

Identify three different key ideas and four to eight concrete, non-identifying anchors from the session. Prepare three portrait concepts, approximately 9:19, with two to four anchors each. They should differ in central form, composition, and color, rather than being one object restyled three times.

The original visual direction uses glass in three distinct ways:

1. Architectural sculpture: panels, ribs, and translucent surfaces; an optional darker technical composition.
2. Spatial drawing: light contours and transparent planes on a pale background.
3. Data sculpture: layered surfaces or flows with at least two recognizable concrete anchors.

Keep at least two concepts light and airy. Default to no people, faces, captions, arrows, or interface elements. Avoid a mystical or threatening atmosphere. The user may choose a different style; the important invariant is that each image recalls a specific idea through distinct concrete objects.

Use an available image-generation tool only within the user's authorized scope. If none exists, provide three image prompts clearly labeled as prompts. Show results and let the user choose which to keep unless they already requested saving all. Do not claim a prompt is a finished image.

## Five interpretation diagrams and two practice diagrams

For the full visual package, prepare up to five source-supported old-to-new transitions and up to two accepted or explicitly tentative practice chains. Create fewer if the session does not support seven; report the gap.

For each old-to-new transition, use three clearly labeled nodes: **underlying interpretation**, **reported unwanted result**, and **conscious explanation**. Place the proposed new understanding in a distinct block below. Arrows show the model discussed in the session; label speculative relations as hypotheses. They do not prove subconscious or environmental causation.

For each practice diagram, connect **chosen new understanding**, **corresponding action or reported result**, and **the client's reading of that experience**. Below, state the proposed repetition loop. Distinguish an expected result from one already reported.

Create original editable SVGs with real text elements and wrapped labels. If the user supplies an existing template, preserve its layout. Use short labels, ample spacing, and a footer with source reference and adoption status. Validate XML, render at full size and about 360×640, inspect readability and overlaps, and repair issues before claiming completion. If rendering is unavailable, deliver the SVG as unverified and say which visual check remains.
