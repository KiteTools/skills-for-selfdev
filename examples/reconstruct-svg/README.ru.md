# Вымышленный пример реконструкции схемы

[English](README.md) · **Русский**

В этом оригинальном примере нет рисунков из учебных курсов или личных данных. [source.svg](source.svg) — намеренно неровный векторный набросок, который играет роль исходного рисунка. [figure.svg](figure.svg) — его аккуратная реконструкция.

Оба изображения передают одну простую связь: **Observation → Experiment → Review** («Наблюдение → Эксперимент → Обзор») и обратный переход **Review → Experiment**. Подписи, направления и структура из трёх узлов сохранены. Пример показывает формат работы; это не научная модель и не реконструкция настоящего PDF пользователя.
