# Из дня — несколько возможных ходов

[English](example.md) · **Русский**

**Вымышленный пример, написанный специально для этого репозитория. Записей чьей-либо реальной активности здесь нет.**

Это фрагмент входных данных и результата, показывающий ожидаемое качество. Он не является полным отбором из двадцати кандидатов и не подтверждает тестовый прогон.

## Переданный контекст

- **e1 · явная запись дневника:** «Я сократил инструкцию для новых волонтёров. Два человека спрашивали, где первый шаг».
- **e2 · явная запись дневника:** «Я прорепетировал десятиминутное выступление. Пример сработал, но вступление заняло четыре минуты».
- **e3 · явная запись дневника:** «Я разбирал карточки с рецептами. Нашёл три простых ужина, для которых нужны почти одинаковые продукты».
- **goal:g1:** «Упростить начало действий, не добавляя новую систему учёта».
- **Покрытие:** только эти три переданные записи. Компьютерная история и полный охват дня не заявлены.
- **История:** предыдущие предложения не переданы, поэтому проверка повторов за четырнадцать дней недоступна.

## Карта до отбора

| Тема | Свидетельство |
| --- | --- |
| Знакомство волонтёров с работой | e1 |
| Репетиция выступления | e2 |
| Подготовка еды | e3 |

## Три примера выбранных пунктов

1. Добавь в начало инструкции для волонтёров строку «Начни здесь» со ссылкой на первое действие. Два прежних вопроса показывают, где не хватило ориентира. **[e1 · смена формата]**
2. Один раз прорепетируй выступление, начав сразу с примера. Сравни, нужно ли после него прежнее четырёхминутное вступление. **[e2 · проверка предположения]**
3. Объедини продукты для трёх похожих рецептов в один список покупок, отдельно указав добавки для каждого ужина. Используй уже найденное совпадение. **[e3 · сочетание ресурсов]**

Это предложения. Само создание фрагмента не означает, что какое-то из них принято, добавлено в задачи или выполнено. Полная десятка сначала рассматривает двадцать кандидатов, выбирает десять и проверяет разнообразие, охват тем и предыдущие предложения, если они доступны.
