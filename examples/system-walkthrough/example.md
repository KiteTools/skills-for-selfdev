# One episode, several useful connections

**English** · [Русский](example.ru.md)

This example is entirely fictional. Each transition depends on the person’s choice.

1. **Source e1:** after a meeting, the person writes: “I interrupted before clarifying the question.” This is self-report.

2. **Reflection:** the agent proposes interpreting questions as rejection. The person has not confirmed this hypothesis; it is not recorded as an accepted belief.

3. **Understanding u1:** the person accepts: “A question may clarify a proposal. I will first understand its meaning.”

4. **Suggestion p1:** ask what needs clarification before answering. Its initial status is interested.

5. **Choice a1:** the person separately chooses to try this at the next meeting. Only now is there a chosen action.

6. **Outcome e2:** “I clarified the question, explained that part, and the conversation continued.” This is a later self-report, not independent verification.

7. **Weekly review:** one episode supports trying the approach. Lasting change is unestablished. No vitality rating was supplied, so that field remains empty.
