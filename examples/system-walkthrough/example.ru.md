# Один эпизод — несколько осмысленных переходов

[English](example.md) · **Русский**

Это полностью вымышленный пример. Все переходы выполняются по выбору человека.

1. **Источник e1:** после встречи человек записал: «Перебил, не уточнив вопрос». Это самоотчёт.

2. **Разбор:** агент предложил гипотезу о восприятии вопроса как отказа. Человек пока её не подтвердил; она не попадает в принятые убеждения.

3. **Понимание u1:** человек сам принял: «Вопрос может уточнять предложение. Сначала выясню его смысл».

4. **Предложение p1:** сначала спросить, что именно требует пояснения. Сначала статус — «интересно».

5. **Решение a1:** человек отдельно выбрал попробовать это на следующей встрече. Только теперь появляется выбранное действие.

6. **Результат e2:** «Уточнил вопрос, объяснил нужное; разговор продолжился». Это последующий самоотчёт, а не независимая проверка.

7. **Недельное ретро:** один эпизод поддерживает полезность выбранного подхода. Устойчивое изменение пока не установлено. Оценку ЖС человек не давал — поле остаётся пустым.
