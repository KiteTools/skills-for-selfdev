# A fictional week: evidence before conclusions

[English](README.md) · [Русский](README.ru.md) · [Skill description](../../docs/skills/weekly-review.md)

This is an original fictional example, not a real diary or a recorded model evaluation. Every episode was invented to illustrate overlap, missing time, and the difference between a decision and application.

## Supplied material

Period: Monday–Sunday, 15–21 April 2030. Timezone: `Europe/London`. The fictional user chose one target: 90 minutes of contact with learning material. They did not set targets for the other lenses.

| ID | Supplied evidence |
| --- | --- |
| W1 | Monday 18:00–19:00: user reports listening to a lecture about clarifying requirements. |
| W2 | Monday 18:30–19:00: timestamped notes contain a paraphrase and a question that challenges one claim in that same lecture. |
| W3 | Tuesday: user reports spending 12 minutes applying the distinction to a personal exercise and noticing that one written criterion reduced rework. |
| W4 | Wednesday: calendar appointment marked attended plus user confirmation of a 25-minute conversation requested by a peer. User also reports 15 minutes of preparation earlier that day. |
| W5 | Thursday: user records “offline conversation; duration not recorded.” No topic or connection to the learning is supplied. |
| W6 | Friday: completed reflection decision, ID `decision-example-1`: “Next time a request is unclear, I choose to ask for the expected result.” There is no later attempt in the material. The same decision appears in a second export. |
| W7 | Saturday: user reports asking a family member what they meant instead of making an immediate assumption. They describe feeling more patient. Duration and the other person's perspective are absent. |
| W8 | Sunday: no notes. No activity-tracking source was supplied. |

A useful clarification would be: “Was Thursday's offline conversation connected to the learning or to someone requesting your help, and do you know its approximate duration?” It does not ask the user to retell Wednesday or reconstruct every missing hour. This example assumes no further answer was provided.

## Example review

The clearest supported connection is Monday's distinction between an instruction and its intended result, followed by Tuesday's reported trial. Saturday may show a related move, but that connection is an interpretation; the user did not explicitly link it to the lecture. Friday records a choice for the future, not proof that the choice was practiced.

Known-duration intervals cover **112 minutes**: Monday 60, Tuesday 12, Wednesday 40. Monday's 30 minutes of notes are inside the lecture hour, not an extra half-hour. This is not total weekly activity. Time in other episodes is unknown, and lens totals overlap.

The observed source-contact total is 60 minutes against the user's 90-minute target. It does not prove a 30-minute weekly shortfall: coverage is incomplete. No target or failure is assigned to the other lenses. Friday's decision is counted once despite its repeated export.

**Pattern worth testing:** specifying the expected result before beginning may help this person reduce avoidable rework. Evidence is one reported trial, not a general causal finding. Wednesday's conversation demonstrates participation, not that the peer understood or benefited.

**One optional experiment:** on one new ambiguous request, ask for a concrete completion criterion before starting. Afterwards note whether it reduced rework, made no difference, or revealed another constraint. This remains a proposal; no task has been created or accepted.

**Limits:** no complete activity timeline, no Thursday duration, no Sunday notes, and no independent observation of inner experience. W7's patience is the user's report. A completed review does not establish completed retraining.
