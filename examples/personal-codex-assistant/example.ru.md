# Вымышленный пример: закончить небольшой прототип

[English](example.md) · **Русский**

Все значения и реплики ниже придуманы для примера. Это иллюстрация результата, а не свидетельство выполнения задачи или оценки реального человека. Не переносите пример в личный журнал как настоящую запись.

## Контекст, выбранный вымышленным пользователем

```json
{
  "schema_version": 1,
  "enabled": true,
  "timezone": "Etc/UTC",
  "l1": "Делать полезные вещи, оставляя место любопытству",
  "l2": [{ "id": "craft", "text": "Заканчивать небольшие инструменты и учиться на их использовании" }],
  "period_focus": { "text": "Один работающий прототип фильтра заметок", "l2_id": "craft", "review_on": null },
  "tasks": [{
    "id": "sample-01",
    "title": "Добавить фильтр по тегу в локальный прототип заметок",
    "l2_id": "craft",
    "acceptance": "Выбор тега оставляет подходящие заметки; сброс возвращает все заметки; соответствующие проверки проходят",
    "status": "open",
    "completed_on": null,
    "completion_evidence": []
  }],
  "vitality": { "enabled": true, "journal_enabled": true }
}
```

Пользователь явно включил журнал в приватной рабочей папке. В поставляемом пустом шаблоне он выключен.

## Начало работы и граница выполнения

Пользователь: «Выполни sample-01. Всё оставь локально».

Ассистент: «Делать полезные вещи с любопытством → заканчивать небольшие инструменты → один работающий прототип → проверенный фильтр по тегу».

Ассистент реализует и проверяет фильтр. В этом вымышленном сценарии автоматическая проверка подтверждает, что выбор тега сужает список, а сброс возвращает все заметки. Только после этого существующая задача получает статус `completed` и запись об этих конкретных проверках. Публикация нигде не заявляется.

Если бы фильтр только обсудили или проверка завершилась ошибкой, задача осталась бы незавершённой и вопроса о жизнеспособности не было бы.

Ассистент: «Локальный фильтр по тегу реализован; проверки фильтрации и сброса проходят. ЖС после работы: −− / − / = / + / ++? Что произошло? Было ли что-то между тобой и живым процессом? „Ничего“ — нормальный ответ».

Пользователь: «+ Мне понравилось, что первая версия заработала. Всё время беспокоился, что она должна выглядеть красивее».

## Одна иллюстративная запись журнала

```json
{"id":"00000000-0000-4000-8000-000000000001","recorded_at":"2026-01-12T16:30:00+00:00","type":"vitality_response","task_id":"sample-01","result":"Локальный фильтр по тегу реализован; проверки фильтрации и сброса прошли","rating":"+","text":"+ Мне понравилось, что первая версия заработала. Всё время беспокоился, что она должна выглядеть красивее.","supersedes":null}
```

Время и UUID вымышлены. В настоящей работе ассистент получает текущее время и создаёт собственный идентификатор события. Ответ сохраняет переживание пользователя; он не ставит диагноз перфекционизма, не доказывает устойчивое изменение и не меняет цель. Последующая поправка добавилась бы отдельной записью со ссылкой на эту.
