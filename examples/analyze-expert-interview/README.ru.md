# Вымышленное интервью: выбор практики на неделю

[English](README.md) · **Русский**

Этот оригинальный английский транскрипт написан специально для репозитория как короткая демонстрация. Он не описывает реальных людей и не цитирует настоящее интервью.

В [interview.vtt](interview.vtt) роли HOST и GUEST указаны явно. Файл подходит для проверки парсера и расчёта метрик. [metrics.json](metrics.json) содержит фактический результат детерминированного расчёта, а не оценку ИИ.

Это не законченный смысловой отчёт и не свидетельство независимого ревью. Пример намеренно не выдумывает пять рекомендаций по крошечному интервью. Чтобы получить полный отчёт в поддерживаемом формате, используйте скилл с достаточно содержательным транскриптом.
