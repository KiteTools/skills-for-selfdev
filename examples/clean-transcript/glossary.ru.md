# Словарь для вымышленного примера

[English](glossary.md) · **Русский**

Русское пояснение к [английскому словарю](glossary.md), который используется с английским исходником.

**Feedback loop — петля обратной связи**: цикл, в котором информация о результате действия используется в последующем действии. Возможная ошибка английского распознавания: «feed back look». Восстанавливать термин следует только тогда, когда окружающая фраза действительно описывает такой цикл.
