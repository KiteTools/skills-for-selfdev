# Вымышленный пример до и после обработки

[English](README.md) · **Русский**

Этот оригинальный учебный пример не содержит личных данных или записи реального курса. Исходные материалы написаны на английском; ниже доступны русские переводы результата и пояснений.

Сравните [сырой английский текст](raw.txt) с [очищенным английским транскриптом](readable-transcript.md) или его [русским переводом](readable-transcript.ru.md). [Словарь](glossary.ru.md) обосновывает одну правку, а [редакторский отчёт](transcript-review.ru.md) объясняет принятое решение.
